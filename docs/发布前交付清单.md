# 发布前交付清单

> 对应 Story：ST-023 发布前打包检查与交付清单  
> 最近更新：2026-06-08

## 交付范围

本次交付面向毕业设计演示与本地验收，覆盖 Web 学生端、Web 管理后台、Spring Boot 后端、原生微信小程序、数据库初始化脚本和项目文档。

## 交付物

| 类别 | 路径 | 说明 |
|---|---|---|
| Web 构建产物 | `vue/dist/` | Vite 生产构建输出，入口为 `vue/dist/index.html` |
| 后端构建产物 | `java/target/canteen-recommendation-1.0.0.jar` | Spring Boot 可运行 Jar |
| 小程序工程 | `miniapp/` | 微信开发者工具可导入工程，配置入口为 `miniapp/project.config.json` |
| 数据库脚本 | `canteen_recommendation.sql` | MySQL 初始化与演示数据基础脚本 |
| 开发文档 | `docs/开发文档.md` | 本地启动、配置和演示说明 |
| 发布前检查脚本 | `scripts/pre-release-check.ps1` | Web/后端打包、关键路径存在性和可选 smoke 检查 |
| Web smoke | `scripts/web-smoke-cdp.mjs` | 浏览器级 Web 核心路由 smoke |
| 后端 smoke | `java/src/test/java/com/school/canteen/smoke/BackendCoreSmokeTest.java` | 登录、下单、支付、评价、积分主链路 smoke |

## 发布前检查命令

在项目根目录运行：

```powershell
.\scripts\pre-release-check.ps1
```

如需同时执行 Web 与后端冒烟测试：

```powershell
.\scripts\pre-release-check.ps1 -FullSmoke
```

脚本完成后应确认：

- `vue/dist/index.html` 已生成。
- `java/target/canteen-recommendation-1.0.0.jar` 已生成。
- `miniapp/project.config.json` 与主流程页面存在。
- `docs/开发文档.md`、`docs/发布前交付清单.md` 和 `canteen_recommendation.sql` 存在。
- 使用 `-FullSmoke` 时，Web smoke 和 `BackendCoreSmokeTest` 均通过。

## 手动交付核对

- Web 端 `.env.production` 中的 `VITE_API_BASE` 指向演示后端地址或同源反向代理。
- 后端运行环境已准备 JDK 17、MySQL、Redis，并按 `docs/开发文档.md` 配置数据库连接。
- 演示数据库已导入 `canteen_recommendation.sql`，演示账号可登录。
- 小程序导入微信开发者工具后，`miniapp/config` 中的 API 地址指向演示后端。
- 支付演示使用 mock 模式时，后端支付配置已切换到 mock provider。
- 演示前先运行 Web smoke、后端 smoke 或 `pre-release-check.ps1 -FullSmoke`。

## 回滚与补救

若发布前检查失败，按失败模块处理：

| 模块 | 常见失败 | 处理 |
|---|---|---|
| Web | `npm run build` 失败 | 根据 Vite/ESLint 编译错误修复对应组件或依赖 |
| 后端 | `mvn package` 失败 | 根据 Maven 编译错误修复 Java 代码或测试依赖 |
| 小程序 | 关键页面缺失 | 检查 `miniapp/app.json` 与 `miniapp/pages/*` 是否一致 |
| Smoke | console/runtime/API 链路失败 | 优先定位最新改动，再重新运行对应 smoke |
