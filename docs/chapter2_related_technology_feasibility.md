# 第二章 相关技术与可行性分析

## 2.1 后端核心技术：Spring Boot

Spring Boot 是当前 Java Web 开发中应用十分广泛的企业级开发框架，它建立在 Spring 生态基础之上，通过自动装配、约定优于配置和统一依赖管理等机制，显著降低了传统 Spring 项目的配置复杂度。对于需要快速构建前后端分离系统的毕业设计项目而言，Spring Boot 既能够提供清晰的分层结构，也能够支持认证授权、数据访问、参数校验、异常处理和接口开发等常见业务需求，因此非常适合作为本系统的后端核心技术。

在本课题中，Spring Boot 主要承担以下几个方面的作用。首先，它用于构建系统的 RESTful 接口服务，实现用户登录注册、菜品管理、订单处理、评价反馈、积分兑换和统计分析等核心业务逻辑。其次，Spring Boot 能够与 Spring MVC、Spring Data JPA、Spring Security 等组件无缝整合，从而形成完整的 Web 应用开发体系。其中，Spring MVC 用于处理请求映射与参数接收，Spring Data JPA 用于简化数据库访问逻辑，Spring Security 用于实现认证与权限控制。再次，Spring Boot 对项目工程结构具有较好的规范作用，能够帮助开发者按照控制层、业务层、持久层进行模块化组织，提高系统的可维护性和可扩展性。

与传统 Java Web 开发方式相比，Spring Boot 在开发效率和工程管理方面具有明显优势。一方面，其自动配置机制减少了大量 XML 配置与样板代码，使开发过程更加高效；另一方面，其内置 Tomcat 容器与 Maven 依赖管理机制使项目部署和运行更加方便，便于开发、测试与后期维护。对于本课题这种包含多个业务模块、需要快速迭代和联调验证的系统，Spring Boot 能够有效降低开发门槛，提高系统实现效率。

因此，选择 Spring Boot 作为校园食堂智能推荐系统的后端开发框架，不仅能够满足业务功能实现需求，也能够为后续系统扩展、模块优化和工程维护提供稳定支撑。

## 2.2 前端核心技术：Vue

Vue 是一种轻量级、渐进式的前端 JavaScript 框架，具有组件化开发、数据驱动更新和较低学习成本等特点，已被广泛应用于中小型以及复杂交互型 Web 系统开发中。对于本课题所实现的校园食堂智能推荐系统而言，前端既需要完成用户端页面展示，也需要实现后台管理界面的数据维护、图表分析和交互控制，因此选择 Vue 作为前端核心技术具有较强的适用性。

在本系统中，Vue 主要用于构建用户端和管理端界面。用户端页面包括登录注册、首页推荐、菜品浏览、购物车、订单管理、个人中心等模块；管理端页面包括用户管理、食堂管理、窗口管理、菜品管理、订单管理、活动配置和统计分析等模块。通过 Vue 的组件化机制，可以将导航栏、推荐卡片、图表面板、表单和列表等页面元素封装为可复用组件，从而提升开发效率并增强代码可维护性。

Vue 的响应式数据绑定机制也是本系统前端实现的重要基础。当用户进行筛选、加购、提交订单、切换页面或查看统计图表时，页面能够根据数据变化自动更新，从而减少手动操作 DOM 的复杂度，提高交互流畅性。此外，Vue 3 可以与 Vue Router、Pinia、Element Plus 等生态工具结合使用：Vue Router 用于实现页面路由管理，Pinia 用于统一状态管理，Element Plus 则提供了较为成熟的后台界面组件和表单控件，使系统能够较快搭建完整的交互界面。

对于毕业设计项目而言，Vue 在开发效率、结构清晰度和用户交互体验方面都具有较大优势。其组件化思想适合构建多页面、多模块的管理系统，响应式特性适合实现菜品浏览、购物车更新和推荐内容刷新等动态功能。因此，采用 Vue 作为本系统前端核心技术，能够有效支撑用户端与管理端的页面实现需求。

## 2.3 数据存储与高性能缓存

在校园食堂智能推荐系统中，数据既包括用户、菜品、窗口、订单、评价、积分、公告等结构化业务数据，也包括推荐结果、热门排行、统计信息等高频访问数据。因此，系统不仅需要稳定可靠的数据存储能力，也需要具备一定的数据读取性能和响应优化能力。基于这一需求，本课题采用 MySQL 作为核心关系型数据库，并结合 Redis 作为高性能缓存组件。

MySQL 是目前应用最广泛的关系型数据库之一，具有开源、稳定、易维护、支持事务处理等优点。对于本系统而言，MySQL 主要用于存储用户信息、食堂信息、窗口信息、菜品数据、订单主表与订单明细、评价记录、积分日志和系统公告等核心业务数据。由于校园食堂业务中存在较多结构明确、关联关系清晰的数据对象，例如用户与订单、订单与菜品、菜品与窗口之间都具有明确联系，因此采用关系型数据库能够更好地保证数据一致性、完整性和可追踪性。此外，MySQL 还支持索引、聚合查询和事务处理，能够满足订单流转、后台统计与历史数据查询等业务需求。

Redis 是一种基于内存的高性能键值数据库，具有读取速度快、支持多种数据结构和适合缓存场景等特点。在本系统中，Redis 主要用于缓存热点数据和提升接口响应效率。例如，在首页推荐、热门菜品、统计概览和部分频繁访问的数据查询场景中，可以将计算结果或查询结果临时存储到 Redis 中，从而减少数据库直接访问压力，提升系统整体响应速度。对于推荐系统而言，部分推荐结果和排行榜数据具有“访问频繁、更新相对周期化”的特点，采用 Redis 缓存能够有效提高用户端体验。

将 MySQL 与 Redis 结合使用，可以充分发挥两者的优势。MySQL 负责保证业务数据的可靠存储和事务一致性，Redis 则负责提升热点数据访问性能和系统并发处理能力。这种“关系型数据库 + 高性能缓存”的组合模式，既满足系统数据管理需求，也符合现代 Web 应用常见的性能优化思路，为校园食堂智能推荐系统的稳定运行提供了良好的技术基础。

从可行性角度来看，上述相关技术均具有成熟的开发生态和广泛的工程实践基础。Spring Boot 能够支持后端业务快速开发，Vue 能够高效完成前端交互页面搭建，MySQL 与 Redis 则能够在数据存储与访问性能之间取得较好平衡。这些技术均具备良好的文档支持、社区资源和学习资料，适合毕业设计项目在有限周期内完成开发、调试与测试任务。因此，从技术实现可行性来看，本课题选用的技术方案是合理且可行的。

## 2.4 本章小结

本章主要介绍了校园食堂智能推荐系统实现过程中所涉及的关键技术，并从技术选型角度分析了系统建设的可行性。后端采用 Spring Boot 框架，能够较好地支撑接口开发、业务分层和权限控制；前端采用 Vue 技术，能够满足用户端与管理端对动态交互和组件化开发的需求；数据层采用 MySQL 进行业务数据存储，并结合 Redis 提升热点数据访问效率和系统整体性能。

综合来看，上述技术方案具有较高成熟度和较强工程适配性，能够满足本课题在开发效率、系统稳定性、功能扩展性和性能优化等方面的要求，为后续系统分析与设计、系统实现和系统测试奠定了坚实基础。
